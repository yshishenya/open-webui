# Open WebUI 0.9.5 и 0.9.6: что нового простым языком

Дата заметки: 2026-06-06

Это короткое пользовательское описание изменений после обновления Open WebUI до версии `0.9.6`.
Оно объединяет полезные изменения из `0.9.5` и `0.9.6` без инженерных деталей.

## Коротко

Обновления `0.9.5` и `0.9.6` сделали Open WebUI заметно удобнее для работы с документами, знаниями, навыками, каналами и администрированием. Плюс добавили много исправлений безопасности и стабильности.

Если в одну фразу: Open WebUI стал меньше похож на просто чат и больше похож на полноценную рабочую систему с базами знаний, правами доступа, каналами, навыками, файлами и более надежной админкой.

## Что стало лучше для пользователей

### 1. Базы знаний стали удобнее

Knowledge Base теперь больше похожа на нормальное файловое хранилище:

- можно раскладывать файлы по папкам;
- можно делать вложенные папки;
- проще искать и понимать, где лежит нужный документ;
- файлы можно переименовывать;
- обработка файлов лучше переживает перезагрузку страницы;
- старые `.doc` файлы теперь тоже лучше читаются, не только `.docx`.

### 2. Появилась нормальная синхронизация базы знаний

Теперь можно синхронизировать базу знаний с папкой, GitHub, S3, Confluence и другими источниками через новый инструмент `oikb`.

Простыми словами: можно держать документы где-то снаружи, а Open WebUI будет подтягивать только новые и измененные файлы, не загружая все заново каждый раз.

### 3. Skills стали удобнее

Раньше skill чаще был привязан к модели или настройкам. Теперь skill можно включать и выключать прямо в конкретном чате через меню Integrations.

Это удобно: в одном чате можно включить "режим юриста", в другом "режим аналитика", в третьем ничего не включать.

### 4. Каналы стали ближе к обычным чатам

Если в Channel упомянуть модель, ответ теперь стримится в реальном времени и лучше поддерживает инструменты, поиск, RAG/knowledge и function/tool calling.

То есть каналы стали не просто перепиской, а более полноценным рабочим пространством с моделями.

### 5. В чатах стало меньше раздражающих багов

Исправили много проблем, которые могли мешать работе:

- чаты меньше застревают в состоянии loading;
- регенерация ответов стабильнее;
- настройки чата лучше сохраняются после обновления страницы;
- прикрепленные знания и файлы меньше отваливаются;
- shared chat links работают надежнее;
- можно надежнее открывать и клонировать shared chats;
- финальный Markdown ответа лучше дорисовывается.

### 6. Появилось больше контроля над ответами

В `0.9.5` добавили возможность редактировать ответ ассистента и продолжать генерацию уже отредактированного варианта.

Это полезно, если модель почти попала, но нужно поправить структуру или кусок текста и продолжить.

### 7. Markdown можно настраивать отдельно

Пользователь теперь может отдельно отключать Markdown-рендеринг для своих сообщений и для ответов ассистента.

Это полезно, когда вставляешь текст с символами, которые Open WebUI раньше мог случайно превратить в форматирование.

### 8. Голос и аудио стали стабильнее

Улучшили voice, speech-to-text и text-to-speech:

- запись голоса работает надежнее в разных браузерах;
- speech-to-text меньше блокирует сервер;
- text-to-speech лучше работает с разными аудиоформатами;
- в Voice Mode появились более аккуратные настройки и горячие клавиши.

### 9. Поиск и документы стали быстрее

Ускорили:

- загрузку страниц;
- web search;
- работу с tools;
- работу с большими knowledge-файлами;
- загрузку prompt/tag списков;
- работу с большими чатами.

### 10. Админка стала понятнее

Админ теперь может посмотреть, что именно доступно конкретному пользователю или группе: какие модели, базы знаний и инструменты.

Это полезно, когда много пользователей, групп, моделей и прав доступа.

### 11. Права доступа стали строже

Много исправлений связано с безопасностью:

- пользователи не должны видеть чужие файлы через knowledge/retrieval;
- нельзя случайно прикрепить чужой файл к модели или чату;
- read-only пользователи не видят скрытые параметры моделей и system prompts;
- skills, calendars, tools и shared chats лучше проверяют права;
- API keys и tool servers стали безопаснее.

### 12. Меньше опасных ссылок и утечек

Закрыли много сценариев, где внешние ссылки, картинки, iframe, web loader или redirects могли использоваться небезопасно.

Для пользователей смысл простой: меньше шансов, что чужой файл, ссылка или HTML в чате сделает что-то неожиданное.

## Самое полезное для нашей установки

- Knowledge Base теперь можно нормально организовывать папками.
- Можно синхронизировать знания из внешних источников, а не руками перезаливать документы.
- Skills теперь можно включать прямо в конкретном чате.
- Админу проще проверить, кто какие модели и знания видит.
- Чаты, shared links, файлы и tools стали стабильнее.
- Reasoning и custom model parameters стали сохраняться корректнее, что важно для наших текущих настроек моделей.
