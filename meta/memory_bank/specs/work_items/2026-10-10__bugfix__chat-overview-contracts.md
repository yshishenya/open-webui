## Поток и Upstream impact

Chat передаёт восстановленную ChatHistory, массивы Model/ChatAttachment и modelId
в ChatControls. Панель выбирает Overview; View создаёт native Node, ссылающиеся
на реальные сообщения истории, пользователя из stores и модель из stores.
Flow передаёт родителю native nodeclick; Node меняет favorite в том же сообщении.
Панель уже сохраняет отсутствие избранного как null — тип должен описывать это.

В ChatControls, Overview, View и Flow нужны точные объявления и удаление
передаваемого Artifacts свойства history, которое этот компонент не принимает
и не использует. Node исправляет отсутствующего пользователя, показ обоих
форматов ошибки через существующий getErrorMessage и использует поддерживаемое
Tooltip.className. Типы графа изолированы в fork-owned frontend-contracts.
Схема БД, провайдерные запросы, платежи, сохранение истории не меняются.

## Уточнение контракта выбранной модели

Chat передаёт null, когда модель не выбрана. CallOverlay сравнивает этот
идентификатор со списком моделей и допускает отсутствие результата, но
необязательная генерация emoji отправляла null в API, ожидающий строку.
Настоящий fetchAudio с управляемыми внешними ответами воспроизвёл этот
неверный вызов. Добавлен один guard выбранной модели: без неё emoji не
запрашивается, синтез речи продолжается. Медиаразрешения и микрофон не меняются.

До исправления: Node — 3 отказа / 1 успех; отдельная проверка отсутствующей
модели обнаружила вызов generateEmoji с null. Первый Node-прогон не дошёл
до тестов из-за отсутствующего APP_VERSION; он сохранён отдельно как ошибка
подготовки, а не как дефект продукта.
