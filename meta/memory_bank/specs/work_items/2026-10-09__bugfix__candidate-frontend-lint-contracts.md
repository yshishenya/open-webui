## Context

Этот этап устраняет данную группу, сохраняя защиту данных, обработку ошибок, подсветку кода и договоры вызовов. Финальная цель A/B и реальные окна пилота продолжают действовать.

## Scope / Upstream impact

Ошибки находятся в существующих API configs/utils, компонентах channel, CodeBlock, MarkdownInlineTokens/MarkdownTokens, CodeEditor/CodeEditorModal и workspace Models. Минимальные изменения объявления и разметки неизбежны для исправления самих диагностик. Переиспользуется существующий DOMPurify action sanitizedHtml; новых зависимостей, выключений правил или переноса небезопасного вывода ради обхода ESLint нет. Удаление неиспользуемых свойств MentionList требует проверки всех вызывающих мест. Общая причина предупреждения ProfilePreview — чтение общего модульного состояния в реактивном выражении; реакция должна зависеть от открытия текущего экземпляра.

## Verification

Docker Compose-first на существующем принятом томе зависимостей. Перед исправлением сохраняется исходный JSON ESLint и снимок файлов. Полный Vitest, svelte-check, ESLint, целевое форматирование, git diff --check; сравнение сообщений с исходным запуском. Для изменения вывода используются настоящие смонтированные компоненты и обновления DOM. Production-выпуск на этом этапе не заявляется.

## Risks / Rollback

Риск: общие компоненты влияют на обычный чат и каналы. Сохраняются обработчики, стили и потребители. Откат — отдельный revert коммита; незавершённые чужие изменения не затрагиваются. Задача chat-dispatch-replay остаётся active до полной приёмки.
