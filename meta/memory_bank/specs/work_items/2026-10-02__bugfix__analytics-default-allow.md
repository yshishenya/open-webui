# Аналитика включена до явного запрета

## Context

Пользователь явно заменил предыдущий opt-in контракт: «Если он не запретил, то она разрешена».
Отсутствие выбора разрешает аналитику; прежний явный запрет сохраняет силу.
Это текущая настройка продукта, не утверждение о юридической достаточности режима.

## Acceptance Criteria

- [x] AC01: свежий браузер без выбора запускает Метрику и first-party полную воронку без клика.
- [x] AC02: сообщение прямо сообщает о включённой аналитике, содержит «Запретить» и «Понятно».
- [x] AC03: сохранённый запрет, ошибочные значения/недоступность storage и незавершённый отзыв исключают сбор.
- [x] AC04: запрет немедленно останавливает новые события, очищает источники/идентичность и отзывает серверную доставку; reload сохраняет запрет.
- [x] AC05: явное повторное разрешение работает после подтверждённого отзыва; privacy/cookies тексты соответствуют механике.
- [x] AC06: Docker проверки, точная frontend сборка на Mac, образ на текущем production backend, backup/rollback/health и браузерная приёмка доказаны.
- [x] AC07: PR в airis_b2c, итоговый статус/SDD и документация завершены.

## Scope / Upstream impact

Общий fork-owned analyticsConsent helper, notice, существующие тесты и пользовательские документы.
Backend API/DB/платежи/зависимости без изменений. Грань backend consent=granted сохраняет технический формат разрешённого состояния.
Tilda, Chatra и другие сервисы без изменений. Для отказавшихся не выдаётся разрешение автоматически.

## Verification / Rollback

Compose frontend tests, scoped lint/format, E2E свежего/запрещённого браузера, сборка и проверка compiled ID/revision.
Общий typecheck/preflight сохраняет ранее согласованные ограничения; backend не меняется.
Выкладка только airis; rollback на реально работающий до неё immutable image.
