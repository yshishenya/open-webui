## Изменение и критерии

API принимает null внутри quotas как безлимитное значение, уже используемое
сервером при проверке квот. Создание/изменение/чтение сохраняют это значение.
Редактор открывает тарифы с null/missing quotas/features, сохраняет неизвестные
ключи квот и не подменяет отсутствие лимита конечным числом.
Отказ сохраняет черновик, повторное нажатие не создаёт второй запрос.
Неполные, бесконечные и дробные значения не проходят проверку формы.
Существующее правило формы: конечные квоты положительные; ноль поддерживается
серверным API для других сценариев и остаётся допустимым там.

## Upstream impact

Две формы и типы существующего административного API; две аннотации серверных
запросов. Нет зависимости, новой подсистемы, повторов записей или изменения
расчётов денег. plan_extra_metadata не редактируется формами; расширение его
серверной поддержки не входит в исправление.

## Проверка и пределы

Воспроизведение до правки, регрессия настоящих компонентов, API на одноразовой
PostgreSQL и общий прогон. Этот блок подтверждает исходники, а выпуск и реальные
платежи/письма/пилот остаются отдельными открытыми критериями общей цели.

## Откат

Откат ограниченного коммита; миграция не нужна. Тома и рабочие данные сохраняются.
