## Context

CodeEditor используется в ответе чата, редакторах инструмента/функции и общей модальной форме. Реактивное if(value) исключает пустое внешнее значение. Глобальный поиск по default id может при двух экземплярах прикрепить оба CodeMirror в первый контейнер. Фоновое форматирование после закрытия или нового ввода может обратиться к уничтоженному редактору либо заменить новые данные старым ответом. Требуется воспроизведение на настоящем смонтированном компоненте.

## Goal / Acceptance Criteria

- [x] Пустое внешнее значение очищает документ; обычное изменение/boilerplate/обратный вызов сохраняются.
- [x] Два экземпляра с default id содержат по одному редактору в своём контейнере.
- [x] Поздний ответ форматирования не меняет текст после нового ввода/закрытия; действующий ответ применяется один раз.
- [x] Worker сообщения/таймеры/события имеют конкретные типы, завершение/ошибка/timeout/закрытие освобождают ресурсы без потери данных.
- [x] Новые регрессионные проверки воспроизводят исходный дефект; полный frontend, types/ESLint/format/diff проверены; новых диагностик0.
- [x] Backend/чужие изменения/production сохранены; SDD и журнал/проверенный коммит отправлены; общая цель остаётся active.

## Scope / Upstream impact

Существующий src/lib/components/common/CodeEditor.svelte: минимально исправить саму общую причину для всех вызывающих мест. Переиспользовать native bind:this, типы CodeMirror и Worker, существующие worker/HTTP formatter; без нового помощника/зависимости. Тесты в src/lib/utils/airis. API/схема не меняются.

## Verification

Docker Compose-first: настоящие смонтированные компоненты jsdom с реальным CodeMirror, управляемым worker/HTTP ответом. Полный frontend и сравнение полных диагностик с предыдущим принятым этапом. Форматирование и сверка исходников/production. Внешний Pyodide/server API и производственный выпуск требуют самостоятельной приёмки.

Общий редактор хранит пользовательский код. Сохранять новые изменения при запаздывающих ответах; отмена форматирования не удаляет код. Откат отдельным revert. Общие types1663/94,ESLint896,Ruff547 и выпуск/пилот остаются открытыми.
