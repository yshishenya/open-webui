## Context

Общая форма вызывается из чата, поля запроса и канала. Закреплённая база bf4e65767 содержит 79 сообщений типов формы, общие 4304 ошибки/176 предупреждений и 1515 ESLint. Синтаксический разбор возвращает default=false как строку, а checkbox считает непустую строку истиной. Select не переносит обязательность. Карта вызывает includes без проверки значения. Работа относится к общему критерию G14; частичное исправление его не закрывает.

## Goal / Acceptance Criteria

- [x] Настоящий компонент воспроизводит строковый false и пустой обязательный select до исправления.
- [x] Флажок согласован с текстом true/false, пустой обязательный select блокируется проверкой формы.
- [x] Строки, CRLF, числа/пустые числа, даты, списки и координаты сохраняют конкретные значения; недопустимый тип не вызывает падение карты.
- [x] Закрытие/повторное открытие сбрасывает значения к текущим defaults; повторная обработка не изменяет исходные данные.
- [x] Все тесты интерфейса проходят; полный завершённый typecheck/lint сокращает исходные сообщения, новых диагностик 0.
- [x] Проверки и обзор относятся к окончательному SHA; PR принят в airis_b2c.

## Non-goals

Платежи, почтовые согласия, рассылка, переписывание синтаксического разбора, новая библиотека форм и общий редизайн. Приёмка исходников не равна выпуску на production.

## Scope / Implementation Notes

Общие типы и безопасное представление скалярных значений в модуле AIRIS; минимальные обработчики в InputVariablesModal. Переиспользуется extractInputVariables/parseVariableDefinition, публичный формат шаблонов сохранён. Все три вызова прослежены. Новых зависимостей, API, миграций и конфигурации нет. package-lock закрепляет Svelte 5.56.0 (package.json задаёт нижнюю границу ^5.53.10); официальный npm latest на 04.10 — 5.57.1. Прочитаны официальные инструкции bind и выпуск 5.56.0. Используются существующие обработчики и нативные поля; обновление всего Svelte не включается в исправление ввода. Путь обновления — отдельная работа dependency upgrade с повторными общими проверками и сверкой с upstream.

## Upstream impact

`src/lib/components/chat/MessageInput/InputVariablesModal.svelte`: общая точка исправления, типы и значения полей. Без перестройки разметки/переименования компонентов; вспомогательные проверки принадлежат AIRIS. `MapSelector.svelte`: nullable координаты и тип callback; пустые markers не вызывают fitBounds, ошибки границ имеют предупреждение. Исправлено закрытие во время zoom: Leaflet1.9.4 завершает таймер после remove() и обращается к удалённому pane. Публичный параметр zoomAnimation:false устраняет анимацию масштаба; изменение масштаба и выбор точки сохранены. Изучены оба вызова карты, её API и закреплённые исходники Leaflet. Минимальная правка общей причины без внутренних методов библиотеки. Другие вызовы меняются только при доказанной необходимости.

## Verification

Docker Compose-first: целевые компонентные тесты, полный Vitest с одним worker, npm run check с 1536 MiB, npm run lint:frontend; сравнение всех диагностик с завершённой базой. Настоящий компонент в браузере с изолированными данными. Backend не меняется.

## Risks / Rollback

False больше не считается истинным из-за строки; обязательный select теперь требует выбора. Нативные ограничения полей сохраняются. Откат — revert отдельного source PR.
