## Причина и объём

TestClient вне контекстного менеджера закрывает цикл каждого запроса.
Настоящая авторизация запускает запись last_active_at отдельной задачей;
закрытие цикла может отменить её во время работы aiosqlite.
В тестах dispatch уже есть проверенная separate_test_loops: постоянный HTTP-цикл
и NullPool для вызовов asyncio.run. Повторно используем эту настройку.
Первый общий строгий прогон нашёл ещё два незавершённых вызова в соседних
тестах. Общая фикстура теперь дожидается задач обновления активности перед
закрытием своего цикла, с пределом 10 секунд и явной ошибкой при отказе.
Новых фикстур, подсистем и зависимостей нет; два существующих тестовых файла.

## Критерии

Наблюдатель сохраняет настоящие auth/SQL вызовы: started == completed,
cancelled == 0. Все проверки сохранения/веток/повтора/JWT/отката остаются.
Общий backend выполняется с ошибкой на PytestUnhandledThreadExceptionWarning.
Исходники интерфейса и приложения неизменны; их проверки переиспользуются
только после сверки контрольных сумм. Общие quality/release/pilot gates открыты.
