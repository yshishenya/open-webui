## Upstream impact

Изменяются только компоненты/утилиты аналитики Airis и целевые проверки. Общие upstream-компоненты, главная страница и настройки продукта не переписываются.

## Verification

Docker Compose-first: Vitest, frontend check/lint, backend report regressions, production build и браузер. Отдельно фиксируются унаследованные ошибки; не ослаблять проверки. npm run preflight отсутствует, используются реальные команды проекта. CI pr-fast, merge-medium и release-heavy привязаны к точной версии.

## Risks / Rollback

Риск устаревшего ответа/неверных дат закрывается исполняемыми проверками. Отчёт read-only. Откат — предыдущий здоровый неизменяемый образ с сохранённой runtime-конфигурацией. Не запускать параллельную выкладку поверх выполняющейся.
