## Context / Goal

Продолжение обязательных проверок выпуска A/B. В CallOverlay отказ play(), отмена и отсутствие элемента не завершают ожидание звука; неудавшийся синтез оставляет очередь в ожидании. Поздний синтез может изменять закрытый звонок. Проверить настоящие обработчики с управляемыми устройствами и порядком ответов.

## Acceptance Criteria

- [x] Воспроизведены исходные ошибки и сохранён отчёт отказов.
- [x] Окончание, отказ, отсутствие элемента, отмена и закрытие завершают ожидание воспроизведения; поздний play не включает звук следующего ответа.
- [x] Прерывание отменяет очередь; новый ответ получает новую очередь; чужое позднее finish не меняет новый ответ.
- [x] Ошибка синтеза пропускается; поздний синтез не записывает cache; все принадлежащие звонку ObjectURL освобождаются.
- [x] Browser speech и Kokoro выбираются по полученному результату; пустой список голосов использует голос браузера без бесконечного опроса.
- [x] Снимок проверяет наличие video/canvas/context и не пишет изображение в журнал; связанные контракты имеют конкретные типы.
- [x] Полный frontend проходит, новых types/ESLint нет; сохранность backend/защищённых файлов проверена; изменения закоммичены и отправлены.

## Scope / Upstream impact

CallOverlay.svelte: существующий AbortController, native события окончания/ошибки, typed cache и проверки после await. VideoInputMenu.svelte: конкретные контракты существующих devices/change. Проверки в fork-owned utils/airis. Без новой зависимости, общей абстракции, schema/API или настоящего доступа к микрофону/камере.

## Verification / Risks

Docker Compose-first: исходные отказы, адресные регрессии и существующие audio/camera lifetime, полный frontend, полный comparison types/ESLint, адресный format/diff. Управляемые устройства не подтверждают приёмку физического телефона. Общая цель и production-выпуск остаются открытыми до всех обязательных критериев.
