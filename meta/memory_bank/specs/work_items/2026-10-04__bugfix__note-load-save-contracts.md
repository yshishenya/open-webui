## Контракты и первопричина

GET возвращает NoteResponse с id/title/data/access_grants/write_access. Модель допускает произвольный словарь data и заменяет null на {}. Редактор требует data.content.json. POST update принимает NoteForm с обязательным title; нельзя заменять его Partial. Сохранение меняет только title/files/grants; содержимое синхронизируется действующей совместной работой. Сервер объединяет data по верхнему уровню.

Один общий таймер читает изменяемые id/note/files после перехода. Нужны захваченный note.id и снимок формы, отдельные таймеры и очередь по записи. Долговечные автономные черновики не входят в это исправление. Права доступа и серверное содержимое не расширять/перезаписывать.
